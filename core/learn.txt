CMake is an open-source, cross-platform build system generator.

It does not compile code directly or create binaries itself; instead, it reads a single configuration file (CMakeLists.txt) and generates the native build files required by your specific OS, compiler, or IDE—such as:

Makefiles for Linux/GCC

Visual Studio solution files (.sln) for Windows/MSVC

Xcode projects for macOS

Ninja files for fast command-line builds
